[01] // about

From security systems to government software.

I started out in the field as a Systems Engineer, deploying CCTV, access control and network solutions with a 100% project completion record. That hands-on hardware background taught me to think about systems end-to-end, from the device to the user.

In 2023 I trained intensively in full-stack web development (MERN, JavaScript OOP, unit testing, C#/ASP.NET), then joined the NCIP Information and Communications Technology Division. Today, as an Information System Analyst II, I co-build the Commission's platforms with Laravel, React and MySQL. I gather requirements, write code, run QA, and train the people who use what we ship.

In 2026 I added project management credentials (CPMS, CASM and CPSCA), so I can plan, schedule and run delivery as well as build.
