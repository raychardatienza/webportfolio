              DevOps Observability // Before & After
              
From Blind Manual Pings to 24/7 Automated Fleet Surveillance

              
Comparing manual reactive IT troubleshooting against the automated SystemOnlineHealth ecosystem.

            

            

              
              
            

          


          
          

            

              
                ✕ BEFORE: Manual / Reactive IT Administration
              
              
    
                
  • •Downtime Discovery: Outages only noticed when employee departments called the IT helpdesk in distress.
    • 
                
  • •SSL Management: Expirations tracked on sticky notes; expired certificates locked users out of government portals.
    • 
                
  • •Threat Visibility: Zero insight into brute-force bot attacks, unauthorized scans, or edge probe bursts.
    • 
                
  • •SLA Reporting: Manual spreadsheet tallying at the end of each month with no MTTR calculation.
    • 
              

            

            

              
                ✓ AFTER: SystemOnlineHealth Automated Telemetry
              
              
    
                
  • •Downtime Discovery: Automated 60-second ICMP socket pings & HTTP probes with instant audio and email alert dispatch.
    • 
                
  • •SSL Management: Proactive certificate crawler alerting administrators 30, 14, and 3 days before expiration.
    • 
                
  • •Threat Visibility: Cloudflare GraphQL API integration streaming real-time WAF telemetry and bot mitigation scores.
    • 
                
  • •SLA Reporting: Interactive 90-day SLA heatmaps, MTTR tracking, and automated daily/weekly executive digests.
    •

+ // Refactored: Non-blocking raw ICMP socket probe with timeout guard & database telemetry
+ public function ping(string $ip, int $timeoutSec = 2): PingResult
+ {
+     $start = microtime(true);
+     $socket = @socket_create(AF_INET, SOCK_RAW, getprotobyname('icmp'));
+     socket_set_option($socket, SOL_SOCKET, SO_RCVTIMEO, ['sec' => $timeoutSec, 'usec' => 0]);
+     $package = $this->buildIcmpPacket();
+     @socket_sendto($socket, $package, strlen($package), 0, $ip, 0);
+     $received = @socket_recvfrom($socket, $buf, 65535, 0, $from, $port);
+     $latencyMs = round((microtime(true) - $start) * 1000, 2);
+     return new PingResult(isOnline: (bool)$received, latencyMs: $latencyMs);
+ }
